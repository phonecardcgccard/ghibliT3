# Ghibli Style AI Image Generator

This is a web application that allows users to generate high-quality Studio Ghibli style images by either entering text prompts or uploading images. The application uses the Pollinations.ai API to generate images without watermarks.

## Features

- Text-to-image generation in Studio Ghibli style
- Image-to-image generation in Studio Ghibli style
- High-resolution image output
- No watermarks on generated images
- Simple and intuitive user interface

## Usage

Simply open the `index.html` file in your web browser to use the application.

1. Enter a text prompt or upload an image
2. Click the "Generate" button
3. Wait for the image to be generated
4. Download the generated image

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Pollinations.ai API
